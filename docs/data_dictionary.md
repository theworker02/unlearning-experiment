# Research data dictionary

All released tables carry `schema_version`. Empty values are never interpreted as zero.

## Experiment registry

| Field | Type | Unit/range | Nullable | Origin |
| --- | --- | --- | :---: | --- |
| experiment_id | text | unique run identifier | no | immutable run configuration |
| maturity | enum | EXPLORATORY/PILOT/VALIDATION/CONFIRMATORY | no | launch declaration |
| dataset | text | benchmark dataset ID | no | dataset registry |
| architecture | text | benchmark architecture ID | no | model configuration |
| method | text | benchmark method ID | no | method registry |
| deletion_regime | text | benchmark scenario ID | no | deletion configuration |
| deletion_fraction | float | [0,1] | no | deletion configuration |
| seed | integer | non-negative | yes | method/run seed |
| runtime_seconds | float | seconds, >=0 | yes | monotonic wall clock |
| validation_status | text | PASS or FAIL with reasons | no | artifact quality gate |
| publication_eligibility | boolean | 0/1 | no | promotion gate |
| raw_artifact | path | repository-relative | no | experiment ledger |

## Split and deletion manifests

`sample_ids` and each split array contain stable source-dataset integer IDs. Hash fields are
lowercase SHA-256 hex digests over the documented canonical JSON encoding. A deletion manifest's
`status` determines whether it is legacy-observed, pilot-frozen, or publication-frozen.

## Raw prediction artifact

Prediction-artifact schema 1 contains `<split>_ids` (int64), `<split>_true_labels` (int64),
`<split>_predicted_labels` (int64), `<split>_logits` (finite float arrays), and
`<split>_probabilities` (finite float arrays whose rows sum to one). These historical files
remain valid and immutable.

Prediction-artifact schema 2 declares `artifact_schema_version=2` inside the NPZ and additionally
requires `<split>_features` for every stored split. Feature rows align one-to-one with split IDs,
are finite float arrays, and are generated by the model's declared `features` interface. Quality
validation rejects a schema-2 artifact that omits or misaligns test features. Future changes to
the meaning or required contents of these arrays require another artifact-schema increment.

## Nullability and units

Unknown historical metadata is null rather than inferred. Times are UTC ISO-8601 strings;
durations are seconds; probabilities and bounded metrics use [0,1] unless a metric registry
entry states otherwise.
